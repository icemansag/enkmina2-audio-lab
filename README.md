## ✨ Características (V1)

- 📤 Subida de audio local (WAV, MP3, FLAC, AAC, M4A, OGG)
- ▶️ Reproductor con play/pause, barra de progreso y volumen
- 🔍 Análisis técnico: duración, sample rate, canales, bitrate, RMS, Peak
- 🔄 Conversión a WAV (16/24/32-bit) y a formatos comprimidos vía códec nativo
- 📊 Visualización de forma de onda
- 🔒 **Procesamiento 100% local** — ningún archivo se sube a servidores

## 🖥️ Uso

Abre `index.html` en un navegador moderno (Chrome, Edge o Firefox).
No requiere build ni instalación.

## 🔐 Privacidad

Todos los archivos se procesan
